\## Objective



To simulate a real-time ticket booking system for movies or events where customers arrive, wait in a queue, book tickets, and view recent bookings. The system demonstrates:



\- \*\*Singly Linked List\*\* for storing all booked customers and movies

\- \*\*Queue\*\* for managing the waiting line (FIFO)

\- \*\*Stack\*\* for recently issued tickets (LIFO)



\---



\## Key Features



\- Enqueue customers in waiting line

\- Issue tickets to next in line → add to booked list \& push to recent bookings stack

\- Cancel bookings

\- Display all movies, waiting line, booked tickets, and recent bookings

\- Interactive menu for Customer and Admin panels



\---



\## Data Structures



| Structure | Usage |

|---|---|

| Singly Linked List | All movies and booked customers |

| Queue (linked list) | Waiting line for ticket booking |

| Stack (linked list) | Recently issued tickets / undo operations |

\## Uniqueness



\- Real-life inspired (queues at cinema, concerts, events)

\- Covers all three core data structure concepts in one system

\- Interactive and easy to demonstrate
